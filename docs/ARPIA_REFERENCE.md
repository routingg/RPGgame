# 아르피아 참고 정리 — 로팅월드 적용안

작성일: 2026-09-16

자료: 사용자가 첨부한 아르피아 문서 본문. 원본 링크는 https://namu.wiki/w/마법학교%20아르피아 이며 웹사이트에 재접속하지 않고 제공된 텍스트를 읽었다. 이 문서는 역사·수치를 검증하는 자료가 아니라 개발 참고와 결정 사항을 정리한 메모다.

## 요소별 반영

| 제공 자료에 설명된 요소 | 로팅월드 적용안 | 시점 |
| --- | --- | --- |
| 마을·학교·상점·회복 시설을 오가는 모험 | 의뢰·회복 NPC가 있는 작은 거점과 숲 하나 | 첫 체험 |
| 필드의 몬스터 구름에 닿아 전투 시작 | 보이는 적 표식과 접촉하면 별도 전투 화면 진입 | 첫 체험 |
| 캐릭터별 행동 게이지와 민첩도 | 순차 턴제로 축소할지 게이지를 구현할지 전투 단계 전에 결정 | 미정 |
| 때리기·마법·아이템·대기·도망 행동 | 공격·마법·회복·도주부터 제안. 대기는 게이지와 함께 검토 | 첫 체험 및 후속 |
| 도주 전 대기, 특정 전투의 도주 제한 | 초기 체험에서는 항상 성공하는 도주 제안. 원작과 다른 간소화 규칙 | 첫 체험 제안 |
| 세 속성의 순환 상성 | 이후 소수의 속성 마법과 상성 표시 도입. 속성 이름은 별도로 정함 | 후속 |
| 의뢰 보상으로 마법·펫 기술 학습 | 레벨 성장 확인 후 기술 학습 NPC와 보상 자원을 함께 추가 | 후속 |
| 펫·NPC 동료가 함께하는 전투 | 첫 버전은 주인공 1명. 동료 또는 펫은 확장 후보 | 장기 |
| 주인공이 쓰러지면 전투 패배 | 첫 버전은 주인공만 있으므로 체력 0이면 마을로 복귀 | 첫 체험 |
| 누적 경험치와 별도의 승급 | 첫 버전은 경험치와 레벨업만. 누적 표시 방식·승급 체계는 미정 | 일부 반영 |
| 마우스 클릭으로 이동 | 첫 이동 구현은 키보드 제안. 클릭 이동 선호도는 실제 체험 후 확인 | 미정 |
| 메인 미션과 프리 미션 | 짧은 독립 의뢰 한 개로 구조를 먼저 확인, 에피소드는 나중에 연결 | 첫 체험 및 후속 |
| 긴 왕복·반복 처치·미로에서의 피로 | 짧은 동선, 적은 요구 처치 수, 현재 목표 표시 | 첫 체험 |

## 그래픽 이해

사용자가 원하는 기준은 화려한 고해상도 배경의 규모가 아니라 작은 캐릭터와 마을을 실제로 돌아다니는 2D 게임의 느낌이다. 그래픽은 캐릭터·길·상호작용 대상이 읽히는 데 우선순위를 둔다. 붙여준 텍스트에는 실제 이미지 대신 이미지 식별자가 있으므로, 이 텍스트만으로 정확한 색상·시점·UI 모양을 확인했다고 주장하지 않는다.

## 유지할 개발 원칙

- 아르피아의 요소를 모두 구현하는 프로젝트로 범위를 넓히지 않는다.
- 로팅월드의 스토리·지명·캐릭터·그림은 따로 만든다.
- 원작의 실제 규칙과 구현 편의를 위한 로팅월드의 축소안을 구분한다.
- 사용자가 확정한 것은 마을 탐험과 턴제 전투를 함께 담는 방향이다. 행동 게이지·속성·펫의 세부 규칙은 아직 확정되지 않았다.
- 당장의 다음 결과물은 작은 시작 화면과 마을, 캐릭터 이동, NPC 대화다. 이후 숲과 전투를 붙인다.

## 현재 구현 메모

배포본에는 작은 시작 화면, 봄들 마을 탐험, NPC 대화가 구현되어 있으며 별도 반복 콘텐츠로 `물방울 광장`이 추가되었다. 물방울 광장은 다른 게임의 이름·캐릭터·그림을 가져오지 않고 물풍선, 상자 파괴, 수집이라는 일반적인 규칙을 로팅월드의 화면과 목표에 맞게 구성한 1인용 미니게임이다. 아르피아에서 참고한 마을 탐험과 향후 턴제 전투 방향은 그대로 유지한다.
